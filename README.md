# YouTube Transcript Scraper

Get timestamped transcripts from any YouTube video or Short, in the spoken language or auto-translated into another language, from Python, JavaScript or the command line. No YouTube API key, no Google Cloud project, no login.

This repository shows how to call the hosted [YouTube Transcript Scraper on Apify](https://apify.com/muhammad_noman_riaz/youtube-video-transcript-super-scraper). The scraper runs in the cloud, rotates residential IPs for you and returns clean JSON.

## What you get

For every video URL:

- `transcript`: segments with `text`, `startMs`, `endMs` and `startTimeText`
- `transcript_only_text`: the whole transcript as one string, ready for ChatGPT, Claude or a RAG pipeline
- `transcriptLanguage`, `isAutoGenerated`, `isTranslated`
- Video details: title, channel, views, likes, publish date, category, thumbnails

Videos without captions are skipped and not charged.

## Quick start (Python)

```bash
pip install apify-client
```

```python
from apify_client import ApifyClient

client = ApifyClient("<YOUR_APIFY_TOKEN>")
run = client.actor("muhammad_noman_riaz/youtube-video-transcript-super-scraper").call(run_input={
    "startUrls": [{"url": "https://www.youtube.com/watch?v=qp0HIF3SfI4"}],
    "language": "default",
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item["title"], item["transcriptLanguage"])
    print(item["transcript_only_text"][:300])
```

## Quick start (JavaScript)

```bash
npm install apify-client
```

```js
import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: '<YOUR_APIFY_TOKEN>' });
const run = await client.actor('muhammad_noman_riaz/youtube-video-transcript-super-scraper').call({
    startUrls: [{ url: 'https://youtu.be/dQw4w9WgXcQ' }],
    language: 'es',
});
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items[0].transcript.slice(0, 3));
```

## Input

| Field | Example | What it does |
|---|---|---|
| `startUrls` | `[{"url": "https://youtu.be/..."}]` | Videos and Shorts; any YouTube URL format |
| `language` | `default`, `en`, `es`, `zh-Hans` | `default` is the spoken language; any other code auto-translates if needed |
| `includeTranscript` | `true` | Turn off for video details only |
| `maxConcurrency` | `10` | Videos processed in parallel |

## FAQ

**Do I need a YouTube API key?** No. The scraper reads the same public captions YouTube shows in its transcript panel.

**What does it cost?** $1.50 per 1,000 videos on the free Apify plan, less on paid plans. Failed videos are not charged. Apify gives every account $5 of free usage each month.

**Can I get transcripts in bulk?** Yes. Pass hundreds of URLs in `startUrls`; they run in parallel.
